
# Source Code

This folder contains the Python source code used for the Structural Damage Recognition project.

## Project Implementation

The source code supports the following activities:

- **Data preprocessing:** Preparing structural images for model training and evaluation.
- **Model training:** Training machine learning and deep learning models for structural damage classification.
- **Model evaluation:** Measuring model performance using accuracy, precision, recall, and F1-score.
- **Prediction and inference:** Generating predictions for structural images.
- **Experimental improvements:** Investigating fine-tuning, data augmentation, Grad-CAM-based region-focused learning, EfficientNetB0, and weighted ensemble classification.
